3. Step-by-step greedy decisions

Greedy rule: Sort by finish time → choose the earliest-finishing compatible activity → repeat.
Compatibility condition: next activity's start time ≥ last selected activity's finish time.

Decision steps will appear here.

What this simulation demonstrates

  • Greedy choice: pick the available activity that finishes earliest.
  • Feasibility: a chosen activity must not overlap the last chosen one.
  • Local choice, global goal: repeat the rule to fit as many non-overlapping activities as possible.
  • Time complexity: sorting takes O(n log n); the selection scan takes O(n), so total time is O(n log n).

This is the classic Activity Selection Problem, where the earliest-finish-time greedy strategy is optimal. Greedy strategies are not optimal for every problem.
